## Featured Projects

### AI Swasthya Sathi
Bilingual (Nepali) healthcare assistant combining computer vision, LLMs, voice interaction, and patient-data management.

Built around **Gemini Live Duplex Streaming** for continuous microphone-to-Gemini-to-speaker conversation; an earlier version used a speech-to-text → Gemini → text-to-speech pipeline with Supabase for interaction logging. Includes a custom **ESP8266-based alert system** with microphone, speaker, webcam, OLED display, and buzzer hardware. Contributed AI integration and database design as part of a team.

🏆 **1st Runner-Up — St. Xavier's SET Exhibition 30**

`Python` `Computer Vision` `Gemini API` `Supabase` `ESP8266` `IoT`

### Neuro-Nod Elite (Contributor: EAR/MAR Detection Module)
Browser-based, Edge AI driver-monitoring system for fatigue and drowsiness detection. Runs entirely client-side with no camera data uploaded.

Uses MediaPipe Face Mesh's 468-point 3D landmarks for EAR-based eye monitoring, 3D head-pose estimation, and MAR-based yawn detection, with EMA signal filtering and per-session calibration. I implemented the **EAR/MAR detection logic**; the project is led by [Upahar Mishra](https://github.com/upahar3000-cloud).

`MediaPipe` `Computer Vision` `Edge AI` `JavaScript`
